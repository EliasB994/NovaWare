## About The Project

NovaWare is a static website serving as a digital proof-of-concept for a business startup idea. This project was conceptualized and developed during my time at the **EY Foundation** as part of their **Dragon's Den Business Startup Challenge**.

The goal was to create a visual identity and a functional landing page to pitch a business concept to a panel of judges a step further than just a presentation.

### Context & Constraints
This project was built under a **strict timeframe** (hackathon style). As such, the focus was on rapid development, visual impact, and structural integrity rather than pixel-perfect code or complex backend logic.

## Built With

* **HTML** - For semantic structure.
* **CSS** - For styling and layout.

## Areas of improvement and limitations

Because this was developed rapidly for a pitch presentation:

The code is raw and unoptimized in certain areas.

Responsiveness may be limited on specific screen sizes.

There is no backend functionality
